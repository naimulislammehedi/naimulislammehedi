```text
Understand

Define Requirements
    ↓
Design
    ↓
Implement
    ↓
Test
    ↓
Debug
    ↓
Optimize
    ↓

    ↓
```

**Readable → Testable → Maintainable → Reliable**

AI is part of my development workflow, but it doesn't replace understanding.

```text
Problem
   ↓
Understand

   ↓

   ↓
```

I use AI for:

* Exploring implementation approaches

* Documentation
* Test generation

The principle is simple:
